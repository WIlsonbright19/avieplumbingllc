# Avie Plumbing LLC

Marketing website for Avie Plumbing LLC, built with React, TypeScript, and Vite.

## Run locally

Prerequisite: Node.js.

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.

## Build

Run `npm run build` to create the static site in `dist/`. Upload the contents of `dist/` to any static web host. The build uses relative asset paths, so it can also be served from a subdirectory.
